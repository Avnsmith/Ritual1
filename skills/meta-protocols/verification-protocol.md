# Verification Protocol

> **Category**: Meta Protocols  
> **Contract / Address**: `12 steps`  
> **Description**: Automated per-skill checks, cross-skill integration, E2E user journey

---

### What it teaches

The complete non-interactive verification system.

### Three layers

*   **Per-skill checks** (T1-T4 tiers): static analysis, simulation, deployed verification, runtime
*   **Cross-skill integration**: 8 interface checks (ABI field counts match, addresses match, event names match, etc.)
*   **Unified 12-step E2E journey**: chain reachable → wallet funded → executor available → contract deployed → wallet funded & balance escrowed → precompile simulates → TX mines → result delivered → result decodable → state updated → frontend renders → backend indexed
