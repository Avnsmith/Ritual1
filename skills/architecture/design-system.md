# Design System

> **Category**: Architecture & Reference  
> **Description**: Dark-mode-first terminal aesthetic, typography, color semantics, accessibility

---

### What it teaches

The Ritual visual language: dark-mode-first terminal aesthetic. Fonts: Izoard (display), Barlow (body), JetBrains Mono (code). Color semantics: green = trust/success, pink = AI/compute, lime = data, gold = value. 9-state lifecycle UI components. WCAG 2.1 AA accessibility with focus-visible rings.
