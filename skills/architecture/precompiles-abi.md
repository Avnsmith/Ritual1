# Precompiles ABI

> **Category**: Architecture & Reference  
> **Contract / Address**: `16 addresses`  
> **Description**: Complete ABI reference for all precompiles with encoding examples

---

### What it teaches

Input/output ABI for every precompile, with field counts, Solidity encoding, and viem TypeScript patterns.

### Precompile Categories

Synchronous ONNX (0x0800), JQ (0x0803), SECP256R1 (0x0100)  
Short-running async HTTP (0x0801), LLM (0x0802), DKMS (0x081B)  
Long-running async Long HTTP (0x0805), ZK (0x0806), Sovereign (0x080C), Image (0x0818), Audio (0x0819), Video (0x081A), Persistent (0x0820)
