# X402 Payments

> **Category**: Precompile Features  
> **Contract / Address**: `via 0x0801 / 0x0805`  
> **Description**: Micropayments for paid API access

---

### What it teaches

X402 micropayment protocol for paid APIs via the HTTP and Long-Running HTTP precompiles.

### Key patterns

*   ECIES-encrypted payment credentials
*   Budget management per API call
*   Shared credential patterns
*   Flows through HTTP (0x0801) and Long-Running HTTP (0x0805), not a separate precompile
