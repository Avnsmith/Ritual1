# Passkey / WebAuthn

> **Category**: Precompile Features  
> **Description**: Sign transactions with Face ID, fingerprint, or hardware keys

---

### What it teaches

Native passkey authentication on Ritual Chain using the TxPasskey transaction type (0x77). Users sign transactions with biometrics (Face ID, Touch ID, fingerprint sensors, or hardware security keys) instead of managing private keys.

### Key patterns

*   P-256 WebAuthn signature verification
*   Wallet-less onboarding: users create accounts with a fingerprint or face scan
*   Recovery patterns and dual-auth (passkey + traditional EOA)
